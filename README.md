# Trabajo Práctico Final de Especialización en Python For Analytics

# Tema seleccionado: Bank Marketing - Dashboard de Análisis Exploratorio de Datos (EDA)

## Descripción del Proyecto:
Aplicación interactiva desarrollada en **Python** con **Streamlit** para el análisis exploratorio de datos de campañas de marketing bancario.
Este proyecto analiza los factores que influyen en la tasa de respuesta y contratación de depósitos a plazo. La aplicación está estructurada en módulos interactivos utilizando visualizaciones avanzadas e interfaces limpias.
